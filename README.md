# ForgePoint AI Website

This repository contains the ForgePoint AI landing page and interactive service business acquisition experience.

## About

ForgePoint AI is built as a static React + Vite single-page application with a brand-aligned marketing experience, interactive valuation calculator, and investor/deal submission workflow.

Key features:
- Hero section with ForgePoint messaging and call-to-actions
- Before/After transformation comparison
- 5-step AI acquisition playbook
- Targeted service vertical cards
- Interactive acquisition valuation calculator
- Deal submission modal for business owners
- Dark glassmorphism theme with animated visuals

## Local development

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite to preview the site.

## Build

Create a production-ready build:

```bash
npm run build
```

Preview the built output locally:

```bash
npm run preview
```

## Notes

The app is currently client-side only and does not include a backend API. The modal form is built for lead capture and can be extended to submit to an endpoint or CRM integration.
